Date: 2026-11-23. BooBoard is GPL-3.0-or-later. This is an engineering inventory, not legal advice. Items marked **decision** need the user's call, and items marked **verify** need a check against the source before release.

## How it was produced

- `tool/audit/licences.dart` reads the Dart packages from `pubspec.lock` and `.dart_tool/package_config.json` (each package's LICENSE file), and the Gradle release runtime classpath (`./gradlew :app:dependencies --configuration releaseRuntimeClasspath --offline`) with each POM from the Gradle cache. The Flutter engine artifacts (`io.flutter:*`) carry no licence in their POMs, so they take the Flutter SDK's own LICENSE.
- Classification is keyword based on the LICENSE text. A file that bundles several licences is reported with its earliest licence as primary and the others listed, with the worst status. The check (`--check`) fails on unknown or incompatible licences, and CI runs it.
- The table at the end is the generated output, unedited.

It is part of the Flutter SDK and is not compiled from BooBoard code. Check it by hand against the Flutter SDK's own licence file before release.
